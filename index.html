Sobre o protótipo

O ClimaAcolhe é uma proposta de aplicativo web para ajudar associações e ONGs a organizar pedidos de apoio de moradores expostos ao calor dentro de suas casas.

Nesta prévia, as telas mostram o fluxo principal do projeto com HTML e CSS básico.

Fluxo demonstrado

  1. Cadastrar uma moradia.
  2. Preencher um check-in térmico.
  3. Visualizar a prioridade no painel.
  4. Registrar uma intervenção comunitária.
Importante: esta versão é somente um protótipo visual. O banco de dados, o cálculo automático do IPTD, login real e o salvamento das informações serão implementados futuramente, após o conteúdo necessário ser estudado na disciplina.
