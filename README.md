# ClimaAcolhe-grupo1101

CLIMAACOLHE - PROTÓTIPO PARA A PRÉVIA 3

Tecnologias usadas:
- HTML5
- CSS básico
- JavaScript

Como abrir:
1. Abra o arquivo inicio.html no navegador.
2. Use o menu e os botões para navegar entre as telas.

Observação:
Os dados são salvos no navegar, não há autenticação por meio de servidor, não ha banco de dados os dados são perdidos

Telas:
- index.html: apresentação do projeto
- cadastro.html: cadastro da moradia
- checkin.html: check-in térmico
- painel.html: painel com dados fictícios
- intervencao.html: registro de intervenção
- login.html: tela de login demonstrativa
