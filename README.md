# ClimaAcolhe-grupo1101

CLIMAACOLHE - PROTÓTIPO PARA A PRÉVIA 2

Tecnologias usadas:
- HTML5
- CSS básico

Como abrir:
2. Abra o arquivo index.html no navegador.
3. Use o menu e os botões para navegar entre as telas.

Observação:
Os formulários, o cálculo do IPTD, o login, os filtros e o salvamento de dados são apenas representados visualmente. Essas funções serão implementadas futuramente, conforme o avanço do conteúdo da disciplina.

Telas:
- index.html: apresentação do projeto
- cadastro.html: cadastro da moradia
- checkin.html: check-in térmico
- painel.html: painel com dados fictícios
- intervencao.html: registro de intervenção
- login.html: tela de login demonstrativa
